# ContentRadar

Бот, який знаходить англомовні статті для авторів цифрового контенту, оцінює їх через GPT,
пише пост українською і надсилає власнику в Telegram. Власник вручну пересилає пост у свій
Telegram-канал або копіює в Threads. Автопублікації немає — і не планувалось на цьому етапі.

Окремий від SkyNovix проєкт (SkyNovix — основна платформа власника, тут її коду немає).
Спілкування з власником — українською, пояснення простими словами.

## Пайплайн (`src/index.ts`)

RSS усіх джерел → лише статті ≤ 3 днів → дедуп по url (Supabase) → правила (`ruleFilter.ts`)
→ до 25 найсвіжіших на GPT → оцінка ≥ `MIN_SCORE` → у бот: беззвучна картка + пост.

- Кожне рішення пишеться в таблицю `Article` (`status`: sent / rejected_rules / rejected_ai, + score, stream, account, reason).
- Стаття записується лише ПІСЛЯ успішної обробки — якщо GPT чи Telegram впали, наступний запуск спробує знову.
- Що не влізло в ліміт 25 — НЕ записується, чекає наступного запуску (раніше це був баг: позначались назавжди).
- Якщо впали всі статті запуску або жодне джерело не відповіло — процес падає з помилкою, щоб спрацювало сповіщення.

## Файли

- `src/sources.ts` — джерела з акаунтом (`creators` | `tools` | `knowledge`). Нові перевіряти `npm run check-sources [групи]` (`scripts/checkSources.ts`).
- `src/summarize.ts` — промпт, схема JSON-відповіді, модель, `MIN_SCORE`, 7 потоків контенту.
- `src/sendToTelegram.ts` — `**жирний**`/`_курсив_` → Telegram HTML (з екрануванням); картка `sendMeta`.
- `src/extractText.ts` — повний текст через Readability + jsdom (вікно jsdom обов'язково закривати, інакше процес висне).
- `src/fetchArticles.ts` — стрічки качаються через `fetch` + `parseString` (не `parseURL`: gzip і 406 на деяких сайтах).
- `.github/workflows/radar.yml` — розклад, при збої шле повідомлення в бот.

## Рішення й домовленості

- Модель `gpt-5.4-mini` (точніша за `gpt-4o-mini`, ~$1–3/міс). Змінюється через env `OPENAI_MODEL`.
- `MIN_SCORE` = 5 (env). Тиждень калібрування з 2026-10-10 — потім переглянути статистику в БД і поріг.
- Пост: 500–1000 символів, живий тон блогера, 2–4 абзаци, 1–3 жирних виділення, підпис «За матеріалами: <платформа>» без лінка. У Threads ліміт 500 — власник скорочує сам.
- Аудиторія: ті, хто продає цифрові продукти, і ті, хто монетизує контент (блогери, стрімери, подкастери, автори на Patreon/Ko-fi/Boosty). Три акаунти: Creators, Tools, Knowledge.
- Розклад: кожні 2 год, 05–19 UTC (8:00–22:00 Київ влітку). Репо приватне — 60-денне автовимкнення cron не стосується.
- Prisma закріплена на 7.10.0 (тег `latest` на npm вказує на 8.0.0-rc — не оновлювати без потреби). Клієнт генерується в `generated/prisma` (у .gitignore; у CI — `npx prisma generate`).
- TypeScript 7 → запуск через `tsx`, не `ts-node`.

## Команди

- `npm start` — повний прогін (пише в БД і шле в бот).
- `npm run preview [N] [send]` — N статей з кожного джерела без БД; `send` — ще й у бот. Для налаштування промпту.
- `npm run check-sources [група…]` — перевірка кандидатів у джерела.
- `npm run typecheck`
- Міграції: `npx prisma migrate dev --name <назва>`, потім `npx prisma generate`.

## Секрети

`DATABASE_URL` (Supabase, Session pooler, порт 5432), `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` —
у `.env` локально і в GitHub Secrets для Actions. При зміні ключа — оновлювати обидва місця.

# ContentRadar

Бот, який шукає **гранти, конкурси, премії, стипендії, резиденції, open call, навчання й безкоштовні події для людей
з креативної сфери** (митці, музиканти, кіно, театр, фото, дизайн, письменники й перекладачі, медіа, геймдев, студенти
творчих спеціальностей), пише пост українською і надсилає власнику в Telegram-бот. Власник копіює пост у свій канал
«✍️ гранти, конкурси та можливості 🇺🇦» (@write_teach_earn) і тизер — у Threads. Автопублікації немає.

Окремий від SkyNovix проєкт. Спілкування з власником — українською, простими словами.

**Історія:** спершу було три канали (Креатори UA, AI для творців, Пиши. Навчай. Заробляй). 2026-10-13 власник лишив
лише гранти (вони набирають перегляди: пост про грант на книжки — 1000 переглядів за 5 хв), два інші канали видалено.
Їхні перевірені RSS-сайти (78) збережено в `src/archive/sourcesArchive.ts` (ніде не підключено). Для тих двох каналів
власник планує іншу генерацію текстів «навколо проєкту» — чекає його пояснень.

## Пайплайн новин (`src/modes/news.ts`)

джерела → лише ≤ 3 днів (без дати — вважаються свіжими) → дедуп по url → `ruleFilter` → дубль за схожістю заголовка
(≥0.7 з надісланими за 30 днів, `makeDuplicateChecker`) → до 50 найсвіжіших на GPT (`analyze`) → лише account
`knowledge` і оцінка ≥ 6 → фактчек (`factCheck`) → `sendPost` → запис у БД.
Стаття записується лише ПІСЛЯ успішної обробки; що не влізло в ліміт — чекає наступного запуску.

## Що вирішує КОД, а не GPT (GPT для грантів нестабільний — оцінка скакала 2↔8)
GPT лише витягує факти, рішення — в `analyze` (`summarize.ts`):
- `deadline` (YYYY-MM-DD) < післязавтра (минув, сьогодні чи завтра — читачі не встигнуть) → ≤2, без поста (УКФ тримав на сайті програми з дедлайнами січня 2026);
- можливість без дедлайну (загальна сторінка програми) → ≤5 (власник зніс такий пост House of Europe);
- `applicants === "orgs_only"` або `creative_sector === false` → ≤2 (власник: «головне, щоб подати могла будь-яка людина»);
- `account === "other"` (звичайна новина, не можливість) → не шлемо.
Плюс `ruleFilter`: агро/медицина/ветерани/ОСББ/соцзахист за словами в заголовку; знижки, огляди тощо.
Лише Україна або програми спеціально для українців (`OPPORTUNITIES` у `gpt.ts`); зарубіжні конкурси — ні.
Події/серії: дедлайн = дата ОСТАННЬОЇ сесії.

## Формат повідомлення (`sendPost`, беззвучно)
```
текст поста (500–1000 симв.; що це, хто подає, суми, дедлайн, умови)
🔗 пряме посилання на форму/сторінку (GPT обирає ЛИШЕ з реальних посилань статті)
#тип #професія            ← channels.ts: #гранти #конкурси #резиденції #стипендії #навчання #події + #музика #кіно …
✍️ гранти, конкурси та можливості 🇺🇦   ← підпис-посилання на канал
———                        ← до лінії — готовий пост, власник копіює
За матеріалами: <ПЕРШОДЖЕРЕЛО>  ← фонд, що оголосив (`origin`), а не агрегатор; «знайдено на: …» — для власника
оцінка/тип, назва статті, «Оригінал», ✏️ правки фактчеку
```
🧵 Тизер для Threads — окремим повідомленням для 8+: ~половина поста, гачок, без головного, кінцівка рівно
«🔗 Більше деталей і посилання на першоджерело — у нашому Telegram. Лінк у шапці профілю.» (`TEASER_END`).
Спільні правила тексту — `gpt.ts` (`AUDIENCE`, `VOICE`, `CLEAR_START`, `LANGUAGE`, `OPPORTUNITIES`, `HOOK_RULES`).

## Інше
- Модель `gpt-5.4-mini` (env `OPENAI_MODEL`). Поріг 6 (`MIN_SCORE_BY_ACCOUNT`), тизер — `HOOK_SCORE` 8.
- 👍 Реакції власника: `SentMessage` + `pollReactions()` на початку кожного запуску (`allowed_updates=["message_reaction"]`;
  Telegram за замовчуванням реакцій не шле). `npm run stats [днів]`.
- Prisma 7.10.0 (тег `latest` на npm — 8.0.0-rc, не оновлювати). TypeScript 7 → `tsx`, не `ts-node`.
- jsdom: вікно обов'язково закривати (інакше процес висне).

## Команди
- `npm start` / `npm start -- saves` — робочий прогін (пише в БД і шле в бот). `ONLY_SOURCES="ГУРТ,УКФ"` — лише ці джерела.
- `npm run preview [N] [send]` — N статей з кожного джерела без БД; `npm run preview saves [send]`.
- `npm run check-sources [група…]`, `npm run stats [днів]`, `npm run typecheck`, `npm run setup-cron`.
- Міграції: `npx prisma migrate dev --name <назва>`, потім `npx prisma generate`.

## 🚀 Пости про SkyNovix для Threads (mode `promo`, з 2026-10-13)
Один запуск = ОДИН суцільний пост (без «1/3» — Threads сам ділить довгий текст на ланцюжок). Лише Threads; у бот.
Джерело правди — `content/skynovix-facts.md` (власник оновлює; «чого нема» → «що підтримуємо», і агент починає про
це писати), стиль/ротація — `content/skynovix-agent.md`. Рішення власника: від бренду «ми»; БЕЗ заклику в кінці
(без «посилання в шапці профілю», без лінків); товари з сайту НЕ публікуємо; 3–5 на день, розкидано по дню.
З 2026-10-17 — 11 форматів корисного контенту (`THEMES`: ідеї товарів, розбір картки до/після, контент-план за рівнями доступу, ідеї рівнів підписки, перший товар, ексклюзив, англ. картка, донати на стрім покроково, помилки, Google), професія чергується по колу (`PROFESSIONS`). Фішка SkyNovix — інструмент усередині поста. Власник забракував «інструкції до каси» (оплата/чекаут/PWYW/валюти/податки) і шаблон «Коли… / Це не X, але Y» — код просить переписати. Стара ротація «по фішках» — `FEATURE_THEMES` (не використовується). Береться найдавніше використаний формат; історія — таблиця `PromoPost`. Назви інших платформ і їхні фічі
(безкоштовне членство, річні підписки, ранній доступ, опитування, мерч) блокує код.
Захист: `FORBIDDEN` (усе з розділу 7 + обіцянки швидких виплат/гарантій заробітку) і відсотки лише 6/8/10/18/5 —
перевіряє код, 1 повторна спроба; потім фактчек проти факт-листа. Код склеює частини й вирізає нумерацію та заклик.
Особливі пости (`SPECIAL`, поза ротацією, `pickTheme` вмикає сам, за пріоритетом):
📅 `payday` — ВИМКНЕНО 2026-10-16 (`PAYDAY_POSTS = false`); 🎁 `holiday` — один пост за 5–12 днів до свята (`HOLIDAYS`: 14.02, 8.03,
6.12, 25.12, 31.12), сезонні товари, без «подарувати товар іншому» (такого немає); 💬 `question` — пост-питання для
коментарів — ВИМКНЕНО власником 2026-10-14 (`QUESTION_POSTS = false`). Кожен пост пишеться в `SentMessage` (format `promo`, тема в `source`) → 👍 власника →
`npm run stats` показує таблицю «тема SkyNovix».
`npm run preview promo send` — тест без запису в БД.

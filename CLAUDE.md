# ContentRadar

Бот, який знаходить англомовні статті для авторів цифрового контенту, оцінює їх через GPT,
пише пост українською і надсилає власнику в Telegram. Власник вручну пересилає пост у свій
Telegram-канал або копіює в Threads. Автопублікації немає — і не планувалось на цьому етапі.

Окремий від SkyNovix проєкт (SkyNovix — основна платформа власника, тут її коду немає).
Спілкування з власником — українською, пояснення простими словами.

## Режими (`src/index.ts` → `src/modes/*`)

Режим — аргумент `npm start -- <mode>` або env `MODE` (його передає `workflow_dispatch` input).

| mode | коли (Київ) | що |
|---|---|---|
| `news` | щодня 8:17–22:17, кожні 2 год | новини з RSS (пайплайн нижче) |
| `tools` | пн 10:47 | 🧰 5 інструментів тижня для Tools і Creators: GitHub Trending + пошук за темами + HF Spaces (`toolSources.ts`); цифри й посилання підставляє код |
| `story` | ср 12:47 | 🔥 вау-історія на акаунт: стаття тижня з найвищим `storyScore` → історія + 🪝 гачок для Threads |
| `evergreen` | вт, чт 16:47 | ♻️ скарбничка зі старих статей архівів (status `evergreen`/`evergreen_sent`/`evergreen_rejected`) |
| `saves` | пт 14:47 | 📌 безкоштовні ресурси тижня з БД — окремий пост на кожен акаунт (якщо набралось ≥3 пункти) |

«Топ місяця» робили й прибрали — власник: лише повторює вже надіслане.
Періодичні формати — о :47, щоб не стартувати разом з новинами. Захист від повторів — таблиці `FormatRun`, `FeaturedItem` (`formatLog.ts`).

Кожен пост — ОДНЕ повідомлення (`sendPost` у `sendToTelegram.ts`), беззвучно:
```
текст поста
#хештег #хештег          ← 1–2 з фіксованого TAGS (channels.ts), GPT обирає
🎨 Креатори UA           ← підпис каналу за акаунтом (CHANNELS у channels.ts: @ukr_creators, @ai_creators_ua, @write_teach_earn — посилання)
———                       ← до лінії — готовий пост для каналу, власник копіює
За матеріалами: <джерело> ← після лінії курсивом — службове: оцінка/потік, назва статті, посилання «Оригінал»
```
✅ Фактчек (`factCheck.ts`) — після написання, перед надсиланням (news, story; evergreen — при наповненні скарбнички):
окремий GPT-запит звіряє пост з оригінальною статтею. Спершу виписує what_is_new / existed_before / limits, потім
"ok" | "fixed" (мінімальні правки + рядок «✏️ фактчек виправив: …» під лінією) | "reject" (не шлемо, reason «фактчек: …»).
Причина: пост про Camera Raw подав давно відомий відбір без каталогу як новинку — у коментарях поправили.
Помилок самого джерела не бачить (для цього був би рівень 2 — веб-пошук, не зроблено).

«За матеріалами» в тексті поста НЕ пишемо (старі пости зі скарбнички чистить `stripAttribution`).

🧵 Тизер для Threads (окреме беззвучне повідомлення «Для Threads» під постом) — для новин і евергріну з оцінкою ≥ `HOOK_SCORE`
(8, env), для всіх вау-історій і тижневих добірок інструментів. Формат за зразком власника: гачок → 1–5 рядків суті без
головного → «…у нашому Telegram» → останній рядок рівно «🔗 Більше деталей і посилання на першоджерело — у нашому Telegram. Лінк у шапці профілю.» (`TEASER_END`, sendHook ставить, якщо нема).
Мета — воронка Threads → Telegram. Правила — `HOOK_RULES` у `gpt.ts`. Поле в БД/коді досі зветься `hook`.

💻 Канал «AI для творців» (account `tools`) з 2026-10-11 — AI для ВСІХ, не лише авторів: безкоштовні AI-інструменти,
відкриті проєкти, нові функції ChatGPT/Claude/Gemini, «як зробити X з AI». Окремі критерії оцінки в промпті (спробувати
сьогодні, безкоштовно, мало хто знає, лише про AI). Геймдев і розробка переїхали в creators.
🔗 Пряме посилання на інструмент: `extractArticle` повертає ще й посилання зі статті, GPT обирає `link` ЛИШЕ з них
(перевіряється кодом), `withToolLink` додає «🔗 url» у кінець поста.

👍 Реакції: кожен робочий пост пишеться в `SentMessage` (message_id → формат/джерело/оцінка). На початку КОЖНОГО запуску
`pollReactions()` (`reactions.ts`) забирає реакції через `getUpdates` з `allowed_updates=["message_reaction"]`, offset — у `BotState`.
Telegram за замовчуванням реакцій не шле — їх вмикає сам виклик з allowed_updates (реакції, поставлені ДО першого такого виклику, втрачено).
`npm run stats [днів]` — що надіслано і що лайкнуто за форматами, акаунтами, джерелами, оцінками.

Спільні для всіх промптів `AUDIENCE`, `VOICE`, `CLEAR_START` (заголовок і перший абзац — простими словами, одразу ясно про що),
`LANGUAGE` — у `src/gpt.ts`.

## Пайплайн новин (`src/modes/news.ts`)

RSS усіх джерел → лише статті ≤ 3 днів → дедуп по url (Supabase) → правила (`ruleFilter.ts`)
→ до 50 найсвіжіших на GPT → оцінка ≥ `MIN_SCORE` → у бот.

- Кожне рішення пишеться в таблицю `Article` (`status`: sent / rejected_rules / rejected_ai, + score, stream, account, reason).
- Стаття записується лише ПІСЛЯ успішної обробки — якщо GPT чи Telegram впали, наступний запуск спробує знову.
- Що не влізло в ліміт 50 — НЕ записується, чекає наступного запуску (раніше це був баг: позначались назавжди).
- Якщо впали всі статті запуску або жодне джерело не відповіло — процес падає з помилкою, щоб спрацювало сповіщення.

## Джерела

71 RSS-джерело (`src/sources.ts`), серед них українські (AIN.UA, MC.today, DOU, Mezha, Детектор медіа, Платформа,
Український інститут) і агрегатори грантів (ГУРТ, Простір — там і УКФ, і House of Europe, у яких власних RSS немає).
Промпт приймає статті англійською й українською; українські — переказувати своїми словами. Гранти/конкурси для українських
авторів з актуальним дедлайном → 8–9 і в пості обов'язково хто може подати, суми, дедлайн; лише для організацій → низько.
Грантові джерела: ГУРТ (розділ грантів), Мінкульт, Мистецький арсенал, Ізоляція — RSS; УКФ, House of Europe, Креативна Європа,
PinchukArtCentre, Простір (його RSS розділу грантів порожній) — без RSS: `linkPattern` у `sources.ts`, `fetchPageLinks` читає
сторінку зі списком і бере посилання за шаблоном; дати немає → publishedAt null (вважаються свіжими, кожне оцінюється раз).
Канал для гранту GPT обирає за змістом (переклад/книжки → knowledge, музика/фото → creators).
⚠️ Дедлайни перевіряє КОД: GPT повертає `deadline` (YYYY-MM-DD), `analyze` порівнює з сьогоднішньою датою (Київ) і минулі
ріже до 2 без поста. Причина: на сторінці УКФ висіли програми з дедлайнами січня–квітня 2026, GPT пропустив їх у жовтні.
Гранти — лише для креативних людей/проєктів: GPT повертає ФАКТИ `applicants` (individuals | individuals_and_orgs | orgs_only)
і `creative_sector`, а код ріже orgs_only і не-креативні до 2 (загальна оцінка GPT для грантів скакала 2↔8). Також
агро/медицина/ветерани/ОСББ/соцзахист відсікає `ruleFilter` за словами в заголовку,
бо GPT вважав «будь-який український грант» цінним. Загальна сторінка програми без дедлайну → максимум 5.
Службові посилання (cdn-cgi/email-protection, login, cart…) `extractArticle` не бере.
Дублі з різних сайтів (той самий грант на ГУРТі, Просторі, сайті фонду): `makeDuplicateChecker` у `dedup.ts` — схожість слів
заголовка ≥ 0.7 з надісланими за 30 днів або з уже побаченими в цьому запуску → rejected_rules «дубль: …», без GPT.
Перевірені й відкинуті кандидати (немає RSS / блокують / покинуті) перелічені в коментарях і списку `scripts/checkSources.ts`.

## Файли

- `src/sources.ts` — джерела з акаунтом (`creators` | `tools` | `knowledge`). Нові перевіряти `npm run check-sources [групи]` (`scripts/checkSources.ts`).
- `src/summarize.ts` — промпт, схема JSON-відповіді, модель, `MIN_SCORE`, 7 потоків контенту.
- `src/sendToTelegram.ts` — `**жирний**`/`_курсив_` → Telegram HTML (з екрануванням); `sendPost` (пост + підпис), `sendHook`.
- `src/digest.ts` — спільний збирач добірок зі статей у БД (saves, evergreen-подібні).
- `src/extractText.ts` — повний текст через Readability + jsdom (вікно jsdom обов'язково закривати, інакше процес висне).
- `src/fetchArticles.ts` — стрічки качаються через `fetch` + `parseString` (не `parseURL`: gzip і 406 на деяких сайтах).
- `.github/workflows/radar.yml` — сам запуск (лише `workflow_dispatch`), при збої шле повідомлення в бот.

## Рішення й домовленості

- Модель `gpt-5.4-mini` (точніша за `gpt-4o-mini`, ~$1–3/міс). Змінюється через env `OPENAI_MODEL`.
- Поріг новин за каналом (`MIN_SCORE_BY_ACCOUNT` у summarize.ts): Креатори UA — 7, AI для творців і Пиши. Навчай. Заробляй — 6 (там статей менше). GPT пише пост від 6, а чи надсилати — вирішує код (GPT плутався з порогом «за каналом»). Базовий `MIN_SCORE` = 7 (env). Спершу був 5, але власник прочитав пости з оцінками 5–6 — мало корисних, підняли до 7.
  Тиждень калібрування з 2026-10-10 — потім переглянути статистику в БД.
- Пост: 500–1000 символів, живий тон блогера, 2–4 абзаци, 1–3 жирних виділення, підпис «За матеріалами: <платформа>» без лінка. У Threads ліміт 500 — власник скорочує сам.
- Аудиторія: ті, хто продає цифрові продукти, і ті, хто монетизує контент (блогери, стрімери, подкастери, автори на Patreon/Ko-fi/Boosty). Три акаунти: Creators, Tools, Knowledge.
- Розклад: кожні 2 год о :17, 05–19 UTC (8:17–22:17 Київ влітку). Живе в Supabase: `pg_cron` + `pg_net` викликають
  GitHub API `workflow_dispatch` (вбудований `schedule` GitHub для цього репо не спрацював жодного разу).
  Налаштовується `npm run setup-cron` (`scripts/setupCron.ts`), токен — у Supabase Vault.
  ⚠️ Токен `GITHUB_DISPATCH_TOKEN` (fine-grained, Actions: Read and write, лише content-radar) діє до 2027-10-10.
  Після цього: новий токен → `.env` → `npm run setup-cron`.
- Supabase free пауза після 7 днів без активності не загрожує: бот і pg_cron звертаються до БД щодня. Репо приватне — 60-денне автовимкнення cron не стосується.
- Prisma закріплена на 7.10.0 (тег `latest` на npm вказує на 8.0.0-rc — не оновлювати без потреби). Клієнт генерується в `generated/prisma` (у .gitignore; у CI — `npx prisma generate`).
- TypeScript 7 → запуск через `tsx`, не `ts-node`.

## Команди

- `npm start` — повний прогін (пише в БД і шле в бот).
- `npm run preview [N] [send]` — N статей з кожного джерела без БД; `send` — ще й у бот. Для налаштування промпту.
- `npm run preview <tools|story|saves|evergreen> [send]` — тест формату без запису в БД.
- `npm run check-sources [група…]` — перевірка кандидатів у джерела.
- `npm run typecheck`
- Міграції: `npx prisma migrate dev --name <назва>`, потім `npx prisma generate`.

## Секрети

`DATABASE_URL` (Supabase, Session pooler, порт 5432), `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` —
у `.env` локально і в GitHub Secrets для Actions. При зміні ключа — оновлювати обидва місця.
`GITHUB_DISPATCH_TOKEN` — лише в `.env` і Supabase Vault (у GitHub Secrets не потрібен).

## Канал можливостей (з 2026-10-13)
Account `knowledge` більше не «письменники», а КАНАЛ МОЖЛИВОСТЕЙ: гранти, конкурси, премії, стипендії, резиденції,
open call, навчання/менторство, безкоштовні події для українських креаторів — УСІ такі матеріали з будь-якої галузі.
Письменницький контент (самвидав, книжки, розсилки, курси) розходиться в creators і tools (AI для письма/навчання).
Грантові джерела мають account `knowledge`, письменницькі — `creators`. П'ятнична `saves` для knowledge = «💰 Можливості
тижня» (відкриті гранти з дедлайнами від найближчого). Назва/юзернейм каналу в `channels.ts` — чекає рішення власника
— «✍️ гранти, конкурси та можливості 🇺🇦» (точно як у власника), @write_teach_earn.

## «За матеріалами» — завжди першоджерело
Правило власника: вказуємо ПЕРШОДЖЕРЕЛО (хто оголосив грант / оригінальне видання / компанія), а не посередника
(ГУРТ, Простір, TLDR, Ben's Bites…). Посередника — лише якщо першоджерело ніде не назване. GPT повертає `origin`,
news.ts підписує `origin || source`; під лінією для власника — «знайдено на: <сайт>», якщо вони різні.
